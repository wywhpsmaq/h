游戏说明

  • 控制方式 - 使用键盘方向键（↑, ↓, ←, →）移动玩家角色。您也可以使用WASD键进行移动。
  • 游戏目标 - 从起点位置（●）移动到终点位置（★）。避开墙壁（深蓝色方块），沿着路径（深灰色方块）前进。
  • 路径提示 - 点击"路径提示"按钮显示最佳路径的第一步（黄色高亮）。每2秒可使用1次提示，总共5次。使用提示不增加步数。
  • 计时系统 - 游戏会自动计时，到达终点后显示通关时间和移动步数。尝试用最短时间和最少步数完成迷宫！
  • 随机迷宫 - 每次开始新游戏都会生成一个全新的随机迷宫。迷宫大小在10×10到25×25之间随机变化，每次都是新的挑战！
  • 挑战自我 - 完成迷宫后，您可以尝试挑战更少步数或更短时间。分享您的成绩给朋友，看看谁能更快完成！
