🎯 堆的定义

堆是一种特殊的完全二叉树，它满足一个重要的规则：

  • 大根堆：每个节点的值都 ≥ 它的孩子节点的值（父亲总是最大的！）
  • 小根堆：每个节点的值都 ≤ 它的孩子节点的值（父亲总是最小的！）

这个演示使用的是大根堆，所以最大的数字永远在最上面（根节点）。

🌲 什么是完全二叉树？

想象你在往一个"金字塔"里放球：

  • 必须从上往下、从左往右依次放
  • 每一层必须放满了，才能放下一层
  • 最后一层可以不放满，但必须是靠左排列的

📦 用数组存储堆

堆可以用一个一维数组来存储！规则非常简单：

  • 根节点放在 h[1]
  • 节点 h[i] 的左孩子在 h[i*2]
  • 节点 h[i] 的右孩子在 h[i*2+1]
  • 节点 h[i] 的父亲在 h[i/2]（整数除法）

⬆️ 插入操作（上浮 up）

往堆里放一个新数字时：

  1. 先把它放到数组末尾（树的最后一个位置）
  2. 然后跟它的父亲比较：如果比父亲大，就交换位置
  3. 重复第2步，直到不比父亲大，或者已经到了根节点

这个过程叫做"上浮"，因为大的数字会像气泡一样往上跑！

⬇️ 删除操作（下沉 down）

从堆里拿走最大的数字（根节点）时：

  1. 先记住根节点的值（就是要拿走的最大值）
  2. 把数组最后一个数字移到根节点位置
  3. 然后跟它的两个孩子中较大的那个比较：如果比孩子小，就交换位置
  4. 重复第3步，直到不比孩子小，或者已经没有孩子了

这个过程叫做"下沉"，因为小的数字会往下掉！

📦 存储顺序（数组视角）

void up(int u)
{
    while (u / 2 && h[u / 2] < h[u])
{
        swap(h[u / 2], h[u]);
        u /= 2;
    }
}

void insert(int x)
{
    h[ ++ cnt] = x;
    up(cnt);
}
void down(int u)
{
    int t = u;
    if (u * 2 <= cnt && h[u * 2] > h[t]) t = u * 2;
    if (u * 2 + 1 <= cnt && h[u * 2 + 1] > h[t]) t = u * 2 + 1;
    if (u != t)
{
        swap(h[u], h[t]);
        down(t);
    }
}
