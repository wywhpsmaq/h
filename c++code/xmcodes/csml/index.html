开发者文档

从创建应用到调用上线，只需 3 步

  • 01

    创建应用

    在控制台创建应用并获取 AppKey 与 SecretKey。

  • 02

    调用接口

    使用 SDK 或 HTTP 请求方式发起 API 调用。

  • 03

    监控运维

    查看日志、余额、限额和调用趋势，实时保障服务质量。

Example Request cURL 
curl --request POST \
  --url https://api.cloudapi.com/v1/ai/chat \
  --header "Authorization: Bearer {token}" \
  --header "Content-Type: application/json" \
  --data '{
    "model": "gpt-4o-mini",
    "messages": [{"role": "user", "content": "你好，帮我写一段企业介绍"}]
  }'

常见问题

开发中遇到的问题，通常都能在这里解决

如何获取 API Key？

登录控制台，进入“应用管理”→“创建应用”，即可获取 AppKey 与 SecretKey。

是否支持多语言 SDK？

支持 Python、JavaScript、Java、Go 等常见语言 SDK，并提供 HTTP 接口示例。

接口调用量有限制吗？

不同套餐支持不同的调用额度，支持按需升级以满足业务扩展需求。
