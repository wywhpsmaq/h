# 1.计划
## 1.1形式
- 主要以HTML作为前端展示，c++作为主要逻辑运算与规划
- 使用Java进行中间交互
## 1.2功能
### 1.2.1第一阶段
#### 1.2.1.1主要功能
- 主要以特殊图形的识别为主。
- 可以生成对应类型的特殊图形，并在前端进行输出。
- 对照片中的物体进行识别，标注出物体的边界框。
- 对识别出的物体进行分类，确定其类别，并在终端进行输出。
#### 1.2.1.2具体实现
- 在本地存储特殊图形，使用图像处理算法进行匹配和识别。
- 实时通过随机数算法生成特殊图形，并将其转换为HTML格式进行展示。
# 2.本地构架
- 1.`~\main.cpp`主要的程序入口，负责整体流程的控制和调用其他模块的功能。
- 2.`~\cc.txt`存储特殊图形的相关信息，包括图形的类型、特征等。
