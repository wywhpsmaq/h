# 800x1600 Matrix Grid 网站

这是一个基于Node.js和Express的网站，用于显示和控制一个800x1600的矩阵网格。

## 功能特点

1. **800x1600矩阵网格** - 无框线设计
2. **API接口** - 可以通过API设置网格中任意单元格的颜色
3. **前端界面** - 提供直观的用户界面来控制网格
4. **缩放和平移** - 支持缩放和平移功能，方便浏览整个网格
5. **实时更新** - 每5秒自动刷新网格数据

## API接口

### 设置颜色

- **URL**: `/api/setColor`
- **方法**: `POST`
- **参数**:
  - `x`: 行号 (0-799)
  - `y`: 列号 (0-1599)
  - `k`: 颜色 (HEX格式，如 #ff0000)

- **示例请求**:
```json
{
  "x": 10,
  "y": 20,
  "k": "#00ff00"
}
```

- **示例响应**:
```json
{
  "success": true,
  "data": {
    "x": 10,
    "y": 20,
    "color": "#00ff00"
  }
}
```

### 获取颜色

- **URL**: `/api/getColors`
- **方法**: `GET`
- **参数** (可选):
  - `x`, `y`: 区域起始坐标
  - `width`, `height`: 区域大小

- **示例响应**:
```json
{
  "success": true,
  "data": {
    "grid": [...], // 800x1600的颜色数组
    "size": {
      "rows": 800,
      "cols": 1600
    }
  }
}
```

## 使用说明

1. **启动服务器**:
```bash
node server_final.js
```

2. **访问网站**:
   打开浏览器，访问 http://localhost:3002

3. **控制网格**:
   - 在输入框中输入行号、列号和颜色
   - 点击"Set Color"按钮设置颜色
   - 使用鼠标滚轮缩放网格
   - 拖动鼠标平移网格
   - 双击网格居中显示

## 技术栈

- **后端**: Node.js, Express
- **前端**: HTML, CSS, JavaScript, Canvas
- **依赖**: express, cors

## 注意事项

- 端口号78913超出了有效范围 (0-65535)，因此使用了端口3002
- 网格使用Canvas渲染，以提高性能
- 颜色数据存储在内存中，服务器重启后会丢失
